# Privacy Policy

_Last updated: [date]_

## Overview

[Business name] ("we", "us") operates this website. This page explains what
data we collect and why.

## Analytics

This site uses privacy-first, cookieless analytics ([Cloudflare Web
Analytics](https://www.cloudflare.com/web-analytics/) / [Plausible](https://plausible.io/) /
[Fathom](https://usefathom.com/) — pick one). It doesn't use cookies, doesn't
track you across sites, and doesn't collect personally identifiable
information. We only see aggregate traffic figures (page views, referrers,
device type).

## Cookies

Because our analytics are cookieless, this site sets no cookies on its own
and therefore ships no cookie-consent banner.

**Exception:** if this site has a Shopify Buy Button embedded on any page,
Shopify's own SDK sets cookies to run the shopping cart. Those cookies are
Shopify's, governed by [Shopify's privacy policy](https://www.shopify.com/legal/privacy),
not ours — remove this note (and the exception) if the site doesn't sell
anything.
